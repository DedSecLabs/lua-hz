   ----Installation----

- You need TXD Workshop and IMG Manager. Download them here:

  TXD Workshop: http://www.gtagarage.com/mods/show.php?id=8320 (OLD version highly recommended).
  IMG Manager: http://www.gtagarage.com/mods/show.php?id=4052

- Using IMG Manager, open up gta3.img on your GTA San Andreas\models folder, then extract the *.txd file of each weapon in the game 
(if you're using this mod with the original weapons, that is. If you're using them with custom weapons, the *.txd files for 
those should already be in their mod's folder). The name of the weapons in the IMG archive is the same one as in my icon files, 
so use them to search for their filenames.

- Open the *.txd files on TXD Workshop. You should see one texture for the weapon and one for the icon. Highlight the icon 
one then press the "Import" button. Choose the folder that contains my icons and click open (you don't need to choose a 
specific icon. They are all correctly named already, so the program will automatically import the correct one for the 
current weapon you're editing). After a succesful import, click "save" then "close". Repeat this for every weapon. For the
Fist icon, you need to edit the hud.txd file located in GTA San Andreas\models.

- Open up gta3.img on IMG Manager again, select "bulk replace" then point to the folder that contains the modified *.txd files. It should
import them all correctly. Rebuild the archive.

- That's it! Have fun with the new looking icons :-) I recommend to use this mod together with yojo2's HQ Radar & Hud icons
mods. You can find them here:

  http://www.gtagarage.com/mods/show.php?id=9182
  http://www.gtagarage.com/mods/show.php?id=8715
