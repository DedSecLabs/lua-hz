=======   MixMods.com.br   ======= - Melhor visualizável em fontes mono-espaçadas, como "Consolas".


------- Instruções:

Escolha uma pasta (PC):

(PC 256) - Boa resolução, suave no minimapa mas no menu é um pouco borrado. Não atrasa o carregamento.
(PC 512) - Alta resolução, pode ficar serrilhado abaixo de 1080p. Caso o desenho demorar pra carregar ao voar rápido etc, use o mod Full Stream Radar.

Extraia a pasta "Proper Radar" para a pasta do ModLoader.

-- Download do Essentials Pack: https://www.mixmods.com.br/2019/06/sa-essentials-pack/

 Se você já tem outro mod de radar, desinstale ou aumente a prioridade deste mod no ModLoader.
 https://www.mixmods.com.br/2015/07/tutorial-dicas-tudo-sobre-modloader-gta/#Priority
 O mod altera o fronten2.txd (opcional) para o mapa do segurar Z no menu. O mesmo arquivo inclui fundo de menu em HD.



Outras plataformas:

(Mobile) - Os arquivos .png para fácil instalação na versão mobile (Android/iOS). Vem em resolução 256, se quiser 512 instale a versão do PC usando algum app de instalar .txd.
(PS2) - Pronto para PS2 (não inclui fronten2.txd) https://forum.mixmods.com.br/f250-tutoriais/t1342-gta-ps2-introducao-pt-br
(Xbox) - Pronto para Xbox clássico (ou retrocompatibilidade no Xbox 360). Instale com algum editor .img, como IMG Manager.
