=======   MixMods.com.br   ======= - Best visualization with monospaced fonts, like "Consolas".


------- Instructions:

Choose a folder (PC):

(PC 256) - Good resolution, smooth on the minimap but the menu is a little blurry. It does not delay loading.
(PC 512) - High resolution, may be aliased below 1080p. If the image takes a while to load when flying fast etc, use the Full Stream Radar mod.

Extract the folder "Proper Radar" to your ModLoader folder.

-- Essentials Pack download: https://www.mixmods.com.br/2019/06/sa-essentials-pack/

 If you already have another radar mod, uninstall it or increase the priority of this mod in ModLoader.
 https://www.mixmods.com.br/2015/07/tutorial-dicas-tudo-sobre-modloader-gta/#Priority
 The mod changes the fronten2.txd (optional) when holding Z map in the menu. The same file includes HD menu background.



Other platforms:

(Mobile) - The .png files for easy installation on the mobile version (Android/iOS). It comes in 256 resolution, if you want 512 install the PC version using some .txd installer app.
(PS2) - Ready for PS2 (fronten2.txd isn't included) https://forum.mixmods.com.br/f250-tutoriais/t1342-gta-ps2-introducao-pt-br
(Xbox) - Ready for classic Xbox (or backwards compatibility on Xbox 360). Install with some .img editor such as IMG Manager.
