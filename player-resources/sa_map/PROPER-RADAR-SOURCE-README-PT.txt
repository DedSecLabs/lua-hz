=======   MixMods.com.br   ======= - Melhor visualizável em fontes mono-espaçadas, como "Consolas".


------- Instruções:


= Como usar:
Abra o .max com 3DS Max (foi salvo no 2020).
Baixe o "radar-sat-8k.png" (atalho no download), que é a imagem de satélite do jogo, em altíssima resolução (montada pela Jéssica Natália).
Use Scene Explorer para esconder o fundo e overlay de radar.
Somente use a câmera "Top" para mover.
Use Slate Material Editor para uma visão simples das cores.


= Como renderizar:
Troque a câmera do scene view para "Top render camera". NÃO MOVA ESTA CÂMERA! Ela precisa ficar em "0.0 0.0 -1000.0".
Abra o Render Setup.
Configure a resolução em "Width" e "Height". Eu recomendo "8192" como base, pois depois você usará ela no SA:DE.
Clique em "Render" e aguarde.
Use o botão de "Save Image" para salvar em .png. A água por volta é a transparência.
Abra em algum editor de imagem, como Photoshop.
Use o conta gotas para pegar a cor da água pequena (por exemplo, em Las Venturas) e pinte o fundo.
Salve a imagem em .png na resolução própria para o radar (por exemplo, 6144 para tiles de 512px, use 8192 somente para a textura do SADE). IMPORTANTE: USE RESAMPLE "BILINEAR"!!!
Para finalizar, compilando em .txd pro GTA clássico, use GTA Radar Creator: https://forum.mixmods.com.br/f44-utilidades/t6092-iii-vc-sa-lcs-vcs-gta-radar-creator-separar-juntar
