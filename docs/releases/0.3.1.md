## Mod Changes

- **Vehicle dashboard:** larger icons, a contrasting lock backing and explicit Locked, Unlocked or Unknown text make the state easier to read. Locked uses amber, Unlocked uses blue, and unknown state stays neutral. The closed-lock artwork now supports color tinting while retaining its exact shape. Energy panel sizes are unchanged, and notifications/oxygen account for the taller vehicle dashboard.
- **Vehicle diagnostics:** `/luahzcapture vehicles` observes vehicle entry, manually used controls, storage/tracking commands and their menu choices. It never sends vehicle actions, omits input text and stops on focus loss, disconnect or its limits. `/luahzcapture carhelp` can request one read-only help response.

This local test build prepares vehicle discovery. Ownership badges, separate Spawn/Track buttons and the Vehicle Controls page are not included yet.
