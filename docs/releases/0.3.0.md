## Mod Changes

- **Quick Actions:** press **U** to clear navigation, lock or unlock a nearby vehicle, track your vehicle, or find a player. The player selector accepts an online name or ID; the server checks detective-job access. Clearing navigation also resets trackers and accepted fares without removing saved places.
- **Server pages:** F9 now includes searchable families and online members, the server rule summary, settings snapshots, community links and observed server version. Refresh quietly collects recognized replies belonging to that request; manual chat commands remain visible. Family rank numbers and names are shown together.
- **Keybinds:** normal shortcuts and command combos have separate tabs. The vehicle-lock preset tries personal locking first and falls back to family locking only after a recognized not-nearby reply. When neither vehicle is nearby, one notice replaces the repeated chat complaints.
- **Command reference:** browse Horizon's `/help` output and LuaHZ commands in separate tabs.
- **HUD and menus:** F9 and Character Status share a wider layout. Stamina and oxygen have labels and wider bars. Notifications match their width and stack above active HUD panels. Oxygen also appears while submerged in a vehicle.
- **Character Status:** a recognized manual `/buylevel` reply can show the respect points remaining until the next level. LuaHZ never requests this purchase command automatically.
- **Installation:** backed-up upgrades preserve preferences and saved locations. Install **SilentPatchSA 1.1 Build 34.1** separately to address the intermittent game streaming freeze encountered during testing.

Server version observations are informational. Server settings are read-only snapshots. Gun-location helpers remain deferred.
