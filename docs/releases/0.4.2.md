## Mod Changes

- **open.mp 1.7.0 loading:** restores the LuaHZ loading artwork and centered loading bar with native client build 7.
- **Launcher choice retained:** the same helper continues to support open.mp 1.6.1/build 6 and classic SA-MP 0.3.7 R5. Use the verified R5 client with either open.mp launcher.
- **Existing setup preserved:** no gameplay features, server commands, artwork, menu behavior or key assignments changed. Preferences and saved locations are preserved by the upgrade installer.

The owner passed the loading-helper checks on Windows 11 in all three configurations. Exact release archive acceptance is recorded separately before publication. Linux source, build and installer checks are separate from gameplay QA; Linux/Wine owner gameplay QA covers the previous 0.4.0 archive.

The native loading adapters recognize only the verified client layouts. The read-only browser-state adapter still recognizes build 6; build 7 uses the ordinary input/render path that the owner reported working. Future open.mp client builds and other SA-MP versions are outside this validation.

**Known baseline limitation:** fresh open.mp launches to other servers can show a black splash in the test setup. This was independently reproduced without LuaHZ before this patch; the upstream cause is undetermined. LuaHZ's custom loading artwork remains exclusive to Horizon.
