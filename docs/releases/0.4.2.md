## Mod Changes

- **open.mp 1.7.0 loading:** restores the LuaHZ loading artwork and centered loading bar with native client build 7.
- **Launcher choice retained:** the same helper continues to support open.mp 1.6.1/build 6 and classic SA-MP 0.3.7 R5. Use the verified R5 client with either open.mp launcher.
- **Sharper Quickmap:** Proper Radar v1.3 — LuaHZ Map Adaptation uses a 3072x3072 combined Quickmap in the classic style. The matching native radar and ESC map retain their existing artwork. Original/base credits and source readmes are included, alongside Zera weapon-icon credits and Rubik's full font license.
- **Three interface themes:** Graphite + Ice Blue is the default, with Midnight + Periwinkle and Carbon + Sea Glass available under Settings / Appearance / Theme. Your choice is saved; Appearance Reset leaves layout settings intact.
- **Compact Quick Actions:** shorter tiles and General/current-job headings make actions easier to scan. Sections follow both job fields when they provide actions; the panel sizes to its content.
- **Sharper HUD lettering:** Science Gothic for HUD/dashboard labels and legacy Pricedown for cash/clock, with original font notices included. Native GTA font resources remain separate.
- **Consistent vehicle presentation:** the K menu and dashboard share themed status colors, explicit state captions and lock shapes. The wider menu aligns with the dashboard; rounded key labels are optically centered. Ownership badges read Personal Vehicle / Family Vehicle, and Storage uses a Pinhead garage icon.
- **Contextual vehicle shortcuts:** Controls uses E/L/O/U/H/B, Trunk uses B/C, and My vehicles uses V/R. Brackets change tabs; Alt/mouse remains available. Configured settings/menu bindings take priority; current-tab actions keep the existing eligibility, deferred commands, confirmation and repeat guards.
- **Clearer on-foot and progress feedback:** driver-only controls explain their restriction; nearby locks/trunk show action descriptions. Quick replies retain their normal labels; longer waits appear once after about one second. Trunk contents show their own loading state and retain existing timeout/error feedback.
- **Vehicle tracker notices:** start/stop status uses the existing bottom-right toast channel, removing the redundant persistent label above the radar.
- **Changelog stability:** percentage signs in older release notes now render as text instead of native format instructions, fixing the reported tab crash.
- **Existing setup preserved:** server commands, loading artwork and configured global bindings are retained. The contextual menu keys are new conveniences for existing actions. Preferences and saved locations are preserved by the upgrade installer.
