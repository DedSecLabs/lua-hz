## Mod Changes

- **Vehicle menu:** K opens a dedicated interface with Controls and My vehicles tabs. It is available on foot as well as inside vehicles. Configure the hotkey in F9; an existing K binding is preserved during migration.
- **Controls:** toggle engine, lights, window, hood, trunk and locks using ordinary server commands. Last-confirmed control states update from matching replies; unknown state stays unspecified.
- **My vehicles:** open the server storage menu or start/stop tracking. Native menus retain the server’s selection and confirmation steps. Stored/empty vehicles do not keep issuing tracking requests.
- **Ownership:** Personal/Family badges reflect matching fresh-entry messages and clear when you exit/change vehicles or reconnect.
- **Quick Actions:** U now focuses on character actions and navigation; vehicle actions moved to K.
- **Readability:** larger, bright lock icons and text share the dashboard background.

This is a local candidate pending owner gameplay QA and icon provenance review before publication. Server permissions remain authoritative.
