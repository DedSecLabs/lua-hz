## Mod Changes

- **Vehicle menu:** K opens a compact panel on the right with Controls, Trunk and My vehicles tabs. Trunk is selected when opening on foot; Controls is selected while seated. Continue walking/driving while it stays visible; hold Alt to click. The key is configurable in F9, preserving an existing K binding.
- **Dashboard:** wider layout with readable Doors, Engine, Lights and Window indicators. Bright colors and labels distinguish confirmed states; unknown states use neutral icons; unavailable states remain explicit.
- **Vehicle controls:** engine, lights, window and hood are available inside as driver; trunk and locks also work nearby on foot. Unsupported server replies end waiting immediately. Trunk balance shows the received slot and resource rows while nearby. Menu inventory requests are silent; typing the command yourself retains normal chat output.
- **My vehicles:** open the server storage menu or start/stop tracking. Native menus keep their selection and confirmation steps; stored/empty vehicles do not keep issuing tracking requests.
- **Ownership:** Personal/Family badges use matching fresh-entry messages and clear on exit/change/reconnect.
- **Quick Actions:** U offers shared navigation, skills, job locations and help, plus actions matched to current jobs. Detective tools appear for detectives. Player/price/crate actions have validated forms.
- **Licenses:** I includes a Licenses tab with a Refresh button and received acquisition statuses.
- **Readability:** larger bright lock icons and labels share the dashboard background.
