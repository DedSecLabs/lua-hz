## Mod Changes

- **Launcher choice:** optional support for open.mp launcher 1.6.1 with native client build 6 and the verified SA-MP 0.3.7 R5 client. Classic SA-MP remains available with the same prerequisites.
- **Loading screen:** LuaHZ artwork appears under the supported open.mp client, with the loading bar centered. The classic loading path is retained.
- **Browser and HUD:** the LuaHZ HUD hides while open.mp's in-game server browser is open, preventing it from covering the browser.
- **Settings shortcut:** Windows key polling and duplicate-event handling make opening and closing the LuaHZ settings menu reliable.
- **Existing setup:** preferences and key assignments are preserved. open.mp uses F9 for its browser; open `/luahz` and choose F12 or another free settings shortcut. The classic default remains F9.

This is a compatibility and quality patch with no new gameplay features or changes to server commands. The owner passed the exact 0.4.1-rc.1 player checklist on Windows 11 in both open.mp and classic SA-MP R5 copies, including the combined helper, menus/input/preferences and server switching. Final 0.4.1 archive smoke acceptance is recorded separately. Linux/Wine owner QA covers the previously published 0.4.0 archive; the new release's Linux checks remain pending.

**Known baseline limitation:** a fresh open.mp launch to another server can show a black splash in this setup. The owner reproduced it with LuaHZ disabled and with MoonLoader, SAMPFUNCS, CLEO and the winmm proxy disabled. SilentPatch and the ASI loader remained; the exact cause is undetermined. The symptom reproduces independently of LuaHZ. LuaHZ's custom artwork remains exclusive to Horizon.
