## Mod Changes

- **Launcher choice:** optional support for open.mp launcher 1.6.1 with native client build 6 and the verified SA-MP 0.3.7 R5 client. Classic SA-MP remains available with the same prerequisites.
- **Loading screen:** LuaHZ artwork appears under the supported open.mp client, with the loading bar centered. The classic loading path is retained.
- **Browser and HUD:** the LuaHZ HUD hides while open.mp's in-game server browser is open, preventing it from covering the browser.
- **Settings shortcut:** Windows key polling and duplicate-event handling make opening and closing the LuaHZ settings menu reliable.
- **Existing setup:** preferences and key assignments are preserved. open.mp uses F9 for its browser; open `/luahz` and choose F12 or another free settings shortcut. The classic default remains F9.

This is a compatibility and quality patch with no new gameplay features or changes to server commands. The owner accepted loading, HUD/browser separation and settings input in the Windows open.mp trial. The unchanged classic SA-MP installation also passed its comparison run. The new combined helper on classic SA-MP, complete Windows feature/server-switching checks and this exact player archive still require owner QA. The previously published 0.4.0 archive passed Linux/Wine QA; that result does not certify this candidate.
