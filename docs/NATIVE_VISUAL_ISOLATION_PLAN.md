# Native isolation implementation and further work

The font/map prototype (0.2.32) and early loading selector (0.2.33) are implemented and user-accepted for the reported Wine normal-launch tests. Native source is in native/; lifecycle details are in ARCHITECTURE.md and SERVER_ISOLATION.md. Further work means compatibility/coverage and packaging, not reintroducing permanent shared-file modifications.

Original game files stay on disk. Separate approved font/icon/map resources activate through a lazily loaded DLL only on HZ. Ownership code retains originals, handles stream-out and restores its own references. Native addresses/layouts come from primary plugin-sdk/gta-reversed/SAMP-API references; metadata/signature checks limit the supported builds. The original DLL/ASI helpers import KERNEL32 only.

Loading appears before Lua/network readiness. The small early ASI selects from launch arguments, verifies the exact original binaries and paired artwork fingerprint, and redirects the SAMPFUNCS getter using its EDX plus caller-cleaned stack argument ABI. Two comparison operands select custom texture/full-screen behavior; bar operand references select the centered footer placement in memory. Unsupported or unknown context uses the original path. Native peer monitoring can disable rendering after a connection transition; separate same-process splash redisplay QA remains useful.

Resources/compiled outputs are private local build products. Fonts, HD radar, Proper Radar and artwork rights/acquisition are recorded in ASSETS.md and manifests. A public build can compile both native code components without those binaries, using the public loading fingerprint. A full visual release requires the matched external assets and a separate distribution decision. RECOVERY.md describes previous working payloads and guarded rollback.
